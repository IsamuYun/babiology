§ 01

品牌定位

Babiology 服务于代孕与卵子捐赠——一个高度私密、周期漫长、决策沉重的领域。品牌要同时传达两件事：可托付的专业性，与有人陪着你的温度。

色彩分工

紫色 #673AB7 承担“可托付”：它比蓝色更有人情味，比粉色更有分量，在医疗与生育服务品类里也足够罕见，不会被误认成竞品。标志里原有的洋红、藕荷、嫩绿承担“温度”：它们是家庭、生长与生命力的直接视觉证据，且不需要重新发明——它们已经在标志里了。

因此本规范的核心结构是：一主三辅。紫色定义所有结构性元素（导航、按钮、链接、强调、深色区块），三种标志色只在需要情绪的地方出现（数据高亮、插图、标签、图形装饰）。

色彩配比

60% 中性

白与偏紫灰。承载正文、留白与图片，是页面的呼吸空间。

30% 主紫

导航、按钮、链接、深色区块、图表主序列。品牌的骨架。

10% 三辅色

洋红点睛、嫩绿表示进展与成功、藕荷做柔和过渡。绝不成片使用。

三辅色同时出现在一屏内不超过两种；洋红与嫩绿不直接相邻（它们在标志里由藕荷隔开，页面上也应如此）。

§ 02

标志

完整标志是「树 + 果实」，figure 舒展成树形，象征养育与延续。favicon 取其躯干与两片叶子，是标志的最小可识别单元。

版本与使用底色

彩色版 / 白底首选。仅用于 #FFFFFF 与 #F8F7FB 两种底色
白色反白版 / 紫底所有深色底一律用此版，不可用彩色版
单色紫版 / 浅底单色印刷、水印、盖章、合作方文档

彩色标志不可置于主紫底：洋红果实与 #673AB7 的对比度仅 1.83:1，藕荷躯干仅 2.45:1，图形会糊成一团。深色底一律使用白色反白版（7.33:1）。

安全边距与最小尺寸

x = 果实直径 x

四周留出的空白不小于 x，x 等于标志中单颗果实的直径（约为标志总高的 1/6）。任何文字、图片、边框都不得进入该区域。

场景最小尺寸
屏幕 · 完整标志32 px 高
屏幕 · favicon 单元16 px
印刷 · 完整标志12 mm 高
刺绣 / 压印20 mm 高

小于 32 px 时改用 favicon 单元，不要缩放完整标志——果实会碎成噪点。

禁止事项

✕彩色版置于紫底或任何深色底
✕置于任何辅助色实底
✓白色或 #F8F7FB 浅底
  • 不拉伸、不倾斜、不旋转，等比缩放。
  • 不替换标志内部配色（洋红/藕荷/嫩绿是固定的），单色需求请用白色版或单色紫版。
  • 不加描边、投影、渐变或外发光。
  • 不置于繁忙照片之上；确需叠图时，先铺 rgba(103,58,183,.86) 蒙版再用白色版。
  • 不与其他 logo 直接拼接，中间至少留 2x 间距。

§ 04

对比度与无障碍

目标 WCAG 2.1 AA：普通文字 ≥ 4.5:1，大字（≥ 24px 或 ≥ 19px 粗体）与图形界面元素 ≥ 3:1。以下为实测值。

组合比值普通文字大字 / 图形结论
#673AB7 on #FFFFFF7.33AAA通过正文链接、标题强调均可
#FFFFFF on #673AB77.33AAA通过主按钮标准组合
#57319A on #FFFFFF9.09AAA通过hover 态更深，安全
#673AB7 on #F5F1FC6.58AAA通过浅紫底上的紫字可用
#EE297B on #FFFFFF4.01不通过通过仅限大标题与图形，正文改用 600
#D91164 on #FFFFFF4.98AA通过洋红文字唯一合规值
#8CC43D on #FFFFFF2.08不通过不通过只能做填充，绝不做文字或图标
#4A6622 on #FFFFFF6.53AAA通过绿色文字请用此值
#6A627A on #FFFFFF5.77AA通过次级文字下限
#B798EE on #14101B7.81AAA通过深色模式主色
#F4C0D6 on #14101B11.93AAA通过深色模式点睛
#9668E8 on #FFFFFF3.86不通过通过只做焦点环与描边

额外规则

  • 颜色不可承载唯一语义。成功/警告/错误必须同时有图标或文案，色盲用户区分不了嫩绿与洋红。
  • 焦点必须可见。统一 2px solid #9668E8，offset 3px；深浅两套主题共用，因为它对白底（3.86:1）和深底（4.86:1）都达标。
  • 正文最小 16px。注释类文字不小于 14px，且必须用 --fg-muted 而非更浅的 --fg-faint。
  • --fg-faint 只用于占位符与装饰性数字，永不承载需要阅读的信息。
§ 05

字体

沿用现有站点已在使用的三套字族，中英文成对配置。衬线负责情绪，无衬线负责信息，等宽负责数据。

角色西文中文用途
--font-textSan Francisco（-apple-system）· Windows 回退 Segoe UIPingFang SC · Windows 回退微软雅黑全站正文、按钮、导航、表单
--font-display= --font-text，标题与正文同族标题层级靠字号与字重拉开
--font-monoSF Mono（ui-monospace）· Windows 回退 Consolas—编号、金额、日期、代码

全站只用系统字体，不下载任何字体文件。西文 San Francisco，中文 PingFang SC —— 两者都是 Apple 专有字体，授权不允许作为 webfont 分发，因此只能通过 -apple-system / "PingFang SC" 的系统字体栈引用，不可自托管。Windows 依次回退 Segoe UI 与微软雅黑。

标题与正文同族，层级只靠字号与字重拉开，不再有衬线对比。因此无衬线的字号阶梯比衬线时代整体收了约四分之一（SF Pro 的 x-height 远大于 Cormorant，同样 px 值视觉上大一圈），并把小标题字重从 500 提到 600。字标 BABIOLOGY / FAMILY 同样使用这一字族。

排版规则

  • 标题一律 text-wrap: balance，字距 -0.015em（display 越大越紧）。
  • 全大写小标题（eyebrow）字距 0.18em，且只用于西文；中文改用 400 字重 + 主紫色，不做字距拉伸。
  • 正文行长 60–75 字符；一屏内不超过两级标题层次。
  • 数字对齐场景（价格、周期、统计）加 font-variant-numeric: tabular-nums。
  • 斜体只用于英文引言与强调单词，不用于中文（中文没有真正的斜体，会被拉斜变形）。

直角规则：所有卡片、banner、图片、输入框与代码块一律使用直角（圆角为 0）。按钮与标签用 --r-btn（2px）——不是胶囊，只是把尖角磨掉一点，让可点击的元件与静态容器之间有一道极轻的区分。除这两者外不要给任何元素加圆角，也不要把 2px 放大成 4px、8px。

投影带紫调（rgba(32,28,41,…)）而非纯黑，与偏紫中性色一致。全站只有一档投影，不做多层级 elevation。

标签与状态

进行中 ✓ 已完成 需补充材料 已归档

状态标签底色用 100 档、文字用 700/800 档，保证 AA。“已完成”带 ✓ 符号——不靠颜色单独表意。

表单

标签置于输入框上方且始终可见（不做 placeholder 当标签）。聚焦时 outline 2px #9668E8，错误态用 #D91164 描边 + 文字说明，不只变红。

链接

正文中的链接使用 主紫 + 下划线，下划线偏移 3px、粗细 1px。导航链接不带下划线，用 hover 变色与 2px 底部指示条表示当前页。链接颜色不做“已访问”变化。

§ 08

动效

这是一个需要让人安心的品牌，动效应当克制。原则：只用于确认状态变化，不用于吸引注意。

场景时长缓动
颜色 / 描边过渡（hover、focus）180ms--ease
展开、折叠、抽屉280ms--ease
滚动进场（淡入 + 上移 12px）520ms--ease
页面切换240msease-out

--ease: cubic-bezier(.2,.7,.2,1)，全站唯一缓动曲线。禁止弹跳（overshoot）、无限循环动画与视差滚动。滚动进场每个区块只触发一次，且必须包裹在 @media (prefers-reduced-motion: reduce) 的降级里。
